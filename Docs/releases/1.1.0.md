# Buddy 1.1.0

My Companion is now called **Buddy**, after its dot-face icon.

- The launcher label, Home header, first-run screen, notifications ("Buddy is running"), the
  quick-actions widget, the pause tile, the share sheet ("Play in Buddy") and the permission steps
  all say Buddy.
- The package stays `dev.akibh.mycompanion` and the signing key is the same as 1.0.0, so this installs
  over 1.0.0 as an update and keeps your data.
- Imported reminder sounds stay in `Notifications/My Companion`, so the ones you already have keep
  playing.

## Updating

Download `buddy-1.1.0.apk` from this release on the phone and open it. Android asks to allow
installs from the browser (or file manager) once, then shows "Update". Your data stays.

Version code 110.
