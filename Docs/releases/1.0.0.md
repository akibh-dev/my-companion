# My Companion 1.0.0

The first production release. For one phone: the Nothing CMF Phone 1 on Android 16 (arm64-v8a).

## New since 0.3

- **Quran** (Arabic only): Madani and Indo-Pak pages, ayah list, search, bookmarks, khatm goal,
  daily reminder, widget and tile.
- **Library**: linked PDF, EPUB and CBZ books with your place remembered, search, bookmarks, shelves,
  reading stats and a widget. The redesigned reader has go to page and a camera-style page dial: push
  up on the strip, then slide to move page by page.
- **Voice mode** reads notifications from any app, with muted apps and block rules.
- **Places**: pick places for context rules on a Google map, with Places search.
- **Buddy**: a new dot-face icon on the launcher, in every notification, and as a launch animation.
- One screen kit across the app (sections, switch rows, empty states, add buttons), the redesigned
  Player, reminder editor, People cards and a calmer Home.

## Fixes and hardening (Plan 19)

- Daily, weekly and monthly reminders keep their clock time across timezone and daylight-saving
  changes.
- A reminder that comes due with notifications off is flagged **Missed** (Home shows how many)
  instead of vanishing. Snoozing a paused reminder rings again, a double tap on Save makes one
  reminder, and reminders no longer replace the background-features notification.
- Context rules always put back what they changed, even when interrupted, and leave alone a setting
  they can't read.
- Settings restore finishes even if you leave the screen; a backup from a newer version is refused.
- Player: Shuffle starts on a random track; an expired stream is retried again after it recovers.
- Bangladeshi numbers written as +880 0… match WhatsApp and contacts; auto-reply no longer answers
  its own re-posted message; missed-call SMS texts only the call that just ended, and only if missed.
- Pause tile and widget can't get out of step on a double tap; reminder times in another year show
  the year.
- Crashes and failed background jobs now leave a line in the in-app Log; one bad reminder no longer
  stops the rest being restored after a reboot; a YouTube change shows "needs an update" instead of
  crashing.
- Other apps can only play, pause, seek and skip in the player (system UI, lock screen, Bluetooth and
  notification-access apps keep full control); queued items and artwork are validated.
- Only the app's own screens open from another app's intent; imported settings are clamped and
  backup files capped at 4 MB; Android backups include the database write-ahead log.

## Release build

- Signed with a dedicated release key (no longer the debug key), minified and resource-shrunk with R8.
- The app's log no longer goes to logcat in release.

## Installing

**Coming from 0.3.x:** the signing key changed, so Android won't install this over the old app, and
a fresh install starts empty. What can come along:
1. In the old app, Settings → Export & backup → **Save settings…**: feature switches, voice mode and
   auto-reply settings, Quran bookmarks and the library list. (**Export my data…** is a readable ZIP
   of everything, but it can't be imported.)
2. Uninstall the old app, install `my-companion-1.0.0.apk`.
3. Settings → Export & backup → **Restore settings…**, re-grant the permissions, and re-link the book
   files. People, reminders, playlists, rules, places and reply templates are set up again by hand.

From now on, later releases install over 1.0.0 as normal updates.

Version code 100.
