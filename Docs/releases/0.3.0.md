# My Companion 0.3.0

- Monochrome light/dark UI with dotted headings, Inter body text and the dotted-M icon.
- Floating glass navigation that contracts while scrolling, with a smooth moving selection pill and immediate page changes.
- Reminders list with a separate editor, visible wrapping interval choices and a compact sound selector.
- Separate WhatsApp voice/video buttons, verified through the app on CMF Phone 1.
- Phone-permission recovery for WhatsApp's protected call activity, with chat fallback when direct calling is unavailable.

Requires Android 16 or newer (API 36+). Existing app data is preserved when installing as an update with the same signing key.

Contacts permission finds WhatsApp-owned contact actions. Phone permission is requested when the installed WhatsApp handler requires it. Direct calling depends on a matching action exposed by WhatsApp; unavailable/failed handoffs retain chat fallback.

This personal-app release uses the repository's existing Android debug signing certificate for upgrade compatibility. The APK is built using the non-debuggable release variant. No keystore, credentials, device contacts, diagnostic reports or test APK are included in the release bundle.
